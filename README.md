# FanControl

Утилита в строке меню macOS для управления вентиляторами. Замена Macs Fan Control с тремя режимами:

| Режим | Что делает |
|---|---|
| **Максимум** | Все вентиляторы на максимальных оборотах (на MacBook Pro M1 Pro это 5779 / 6241 об/мин). |
| **Выкл** | Вентиляторы остановлены при любой температуре. Защиты от перегрева нет, остаётся только троттлинг самого чипа. |
| **По темп.** | Обороты задаются ступенями по температуре самого горячего ядра ЦП. Есть готовые наборы ступеней «Тихо», «Баланс» и «Производительность»; ступени можно и настроить вручную прямо в меню. |

Ещё в меню:
- история температуры и оборотов за 10, 20 или 30 минут (переключатель «Температура ЦП / История» на синей панели, при наведении видно точное значение);
- готовые наборы ступеней «Тихо», «Баланс», «Производительность»;
- иконка в строке меню перечёркнута, когда вентиляторы остановлены.

Иконка в строке меню показывает состояние: вентилятор перечёркнут, когда вентиляторы стоят, и помечен буквой «A», когда помощник недоступен и вентиляторами управляет macOS.

Настройки в меню:
- температура и обороты рядом с иконкой в строке меню;
- отдельный режим для каждого вентилятора;
- запуск при входе в систему.

При закрытой крышке вентиляторы останавливаются в любом режиме. Если ЦП нагреется до 90 °C, снова включается выбранный режим, пока температура не опустится ниже 80 °C.

Выбранный режим и ступени сохраняются и восстанавливаются после перезапуска. Когда приложение закрывается (или падает), вентиляторы возвращаются под управление macOS.

## Требования

- macOS 13 Ventura или новее (проверено на macOS 26.6, MacBook Pro M1 Pro).
- Xcode или Command Line Tools со Swift 5.9+ (`xcode-select --install`). Apple ID и платный аккаунт разработчика не нужны.
- Права администратора: один раз при установке.

## Сборка и установка

```bash
cd ~/Documents/Programming/FanControl
```

```bash
./scripts/build.sh
```

```bash
./scripts/install.sh
```

Что делают скрипты:

1. `build.sh` собирает `swift build -c release`, упаковывает `build/FanControl.app` (приложение и помощник `fancontrold` внутри бандла) и подписывает его локальной подписью (ad-hoc).
2. `install.sh` спрашивает пароль (sudo) и:
   - копирует помощник в `/Library/PrivilegedHelperTools/com.george527.fancontrol.helper`;
   - регистрирует LaunchDaemon `/Library/LaunchDaemons/com.george527.fancontrol.helper.plist`;
   - копирует приложение в `/Applications/FanControl.app` и запускает его.

Macs Fan Control устроен так же: интерфейс плюс root-помощник `smcwrite`.

После установки в строке меню появится иконка вентилятора. Зелёная точка в заголовке меню означает, что помощник подключён.

macOS может показать уведомление «Добавлен фоновый объект». Это наш помощник. Он должен быть включён в «Системные настройки → Основные → Вход и расширения».

> Перед первым запуском закрой и удали Macs Fan Control. Два приложения, пишущие в SMC, будут перебивать друг друга, и `install.sh` предупредит, если он запущен.

### После изменения кода

Достаточно снова выполнить `./scripts/build.sh && ./scripts/install.sh`. Помощник переустанавливается, только если менялись `Sources/fancontrold`, `Sources/SMCKit` или `Sources/FanControlShared`, но перезапуск install.sh безопасен всегда.

### Сборка в Xcode (для редактирования)

`open Package.swift` откроет проект в Xcode. Для релизной `.app` всё равно используй `scripts/build.sh`, потому что он собирает бандл и Info.plist.

Отладочная сборка умеет рисовать меню в картинку без запуска в строке меню:

```bash
swift build && .build/debug/FanControl --snapshot /tmp/menu.png
```

## Удаление

```bash
./scripts/uninstall.sh
```

Скрипт удаляет приложение, помощник, автозапуск и настройки, а вентиляторы возвращает macOS.

## Как это устроено

```
FanControl.app (пользователь)              fancontrold (root, LaunchDaemon)
 ├─ читает SMC: температуры, обороты        ├─ XPC-сервис com.george527.fancontrol.helper
 ├─ раз в 2 с считает целевые обороты  ──►  ├─ пишет в SMC только F<n>Md (режим) и F<n>Tg (обороты)
 └─ при выходе: resetToAuto            ──►  └─ при обрыве связи / 12 с без команд / SIGTERM → авто
```

- `Sources/SMCKit`: доступ к SMC через IOKit (`AppleSMC`): чтение и запись ключей, перебор всех ключей, декодирование типов `flt`, `fpe2`, `sp78`, `ui8/16/32`.
- `Sources/fancontrold`: root-помощник. Принимает подключения только от приложения с идентификатором подписи `com.george527.fancontrol` и не даёт писать произвольные ключи SMC.
- `Sources/FanControl`: приложение на SwiftUI (`MenuBarExtra`).
- `Resources`: Info.plist, plist LaunchDaemon, иконка. `scripts/make_icon.swift` перегенерирует иконку.

### Ключи SMC на этом Маке (M1 Pro)

| Ключ | Значение |
|---|---|
| `FNum` | число вентиляторов (2) |
| `F<n>Ac` / `F<n>Tg` | фактические / целевые обороты (`flt`) |
| `F<n>Mn` / `F<n>Mx` | минимум / максимум (1200 / 5779 и 6241) |
| `F<n>Md` | 0 = авто (macOS), 1 = ручной |
| `Tp**`, `Te**` | датчики производительных и энергоэффективных ядер ЦП |

На M3 и новее для ручного режима нужен ключ `Ftst=1`. Помощник выставляет его сам, только если такой ключ есть.

### Ступени (режим «По темп.»)

- Действует ступень с наибольшим порогом, не превышающим текущую температуру.
- Процент считается от максимальных оборотов каждого вентилятора, но не ниже его минимума. 0 % означает «стоп».
- Вниз ступень переключается, только когда температура опустится на 3 °C ниже порога (гистерезис), чтобы вентиляторы не дёргались.
- Если температуру прочитать не удалось, вентиляторы идут на максимум.

## Не видно иконки в строке меню

На MacBook с вырезом («чёлкой») иконки, которым не хватило места справа от выреза, macOS просто прячет. У FanControl иконка всегда самая левая из сторонних, поэтому она скрывается первой.

- Иконка без текста узкая и обычно помещается. Поэтому опция «Температура и обороты в строке меню» по умолчанию выключена.
- Освободить место можно двумя способами. Первый: «Системные настройки → Строка меню», там отключи лишние значки. Второй: зажми ⌘ и перетащи ненужные иконки вниз из строки меню.
- Запасной вход работает всегда. Открой FanControl ещё раз (Spotlight, Launchpad или двойной клик в /Applications), и панель откроется сама: под иконкой или, если иконка спрятана за вырезом, у правого края экрана.

## Диагностика

- Лог помощника: `/var/log/fancontrold.log`.
- Статус помощника: `sudo launchctl print system/com.george527.fancontrol.helper | head -20`.
- Текущее состояние SMC можно посмотреть в меню приложения. Строка «Ошибка помощника» показывает текст ошибки записи.
